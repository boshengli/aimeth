# AIMeth 科学主计划：任务驱动的细胞自组织与功能涌现

日期：2026-10-02 · 状态：设计计划；尚未实现或冻结实验。

本计划落实 D-032，替代 organization-design-brief.md 中旧的主线表述。旧简报和 next-cycle-candidate v1–v3 保留为历史构想。项目聚焦一个科学目标、两条设计原则；治理、记录和格式是实现或评价机制，不另立科学目标。

## 唯一科学目标

模拟并检验计算细胞群体如何依据任务或后训练，通过自组织、分化与增殖形成介观结构，再组合成组织形态；研究这种发育过程是否带来更强的任务适应与问题解决能力。

同时追踪结构和功能。出现层状、管状或球状形态，说明结构形成；只有在独立任务测评上出现可重复改善，才能支持功能涌现。要记录形态和行为哪些由初始化、全局训练或目标直接规定，哪些由局部交互产生。结构与能力的联系需通过保留组织、打乱或干预局部信号等对照检验，并控制细胞数、模型容量、训练、通信、算力与耗时。

数学是重要的评估领域，因为定理主张可由证明核验，无需湿实验；但数学不是智能的唯一界定。证明本身须经过独立审查；组织是否改善能力则是另一个需用匹配计算实验回答的经验问题。可用留出数学任务和部分非数学迁移任务检测能力与泛化。

## 两条设计原则

### 一、调控驱动细胞发育，从介观结构走向组织

| 概念 | 当前计算定义草案 | 尚待决定 |
|---|---|---|
| 细胞 | 有持久局部状态、局部计算和明确通信边界的计算单元 | Agent、Agent 小组或其他单元；先分别操作化，再比较粒度 |
| 人工基因 | 可激活、抑制、组合或干预的可复用功能模块或局部更新规则 | 提示操作、适配器、子网络、参数组或非语言算子 |
| 表达 | 单个细胞在当前状态下对可用功能模块的激活程度 | 离散开关、连续门控或状态相关策略 |
| 细胞类型 | 与可重复功能行为相关的表达和状态模式 | 离散类型、连续状态或发育轨迹 |
| 发育信号 | 会改变接收单元状态、表达或行为的类型化信息 | 邻接范围、延迟、带宽和信号种类 |
| 增殖 | 按明确规则产生子计算单元，并继承状态和承担额外资源成本 | 任务触发、遗传/变异和停止规则 |
| 组织 | 多个介观结构经持续交互形成的组织关系 | 层状、管状、球状，或由局部规则自行形成的结构 |

共享功能模块集合可类比人工基因组；各细胞的模块激活谱类似表达状态。任意单个权重不自动等于一个基因，只有能被独立识别、测量和干预的功能模块才是更合适的候选。自然语言不是唯一通信方式，也可传递符号、向量、约束或任务状态变化。

用户提出的尺度作为项目工作范围：数千至数万计算细胞构成介观结构；十几万至百万量级构成由多个介观结构组合的组织。这些是待建模的尺度假设，不是普适生物学界线，也不是当前扩容或启动任务的指令。空间转录组可提供邻域和表达模式的先验，单凭描述性图谱不能确定因果调控。

### 二、快速交互服务于可测的任务能力

把单元能力、局部通信延迟、带宽、网络连接和远距离整合作为可能影响发育与任务表现的因素。检验有限单元能否通过快速局部更新和紧凑的多维信号形成有用组织；不预设速度、单元简单或几何外形必然带来智能。

同时测量端到端任务质量、适应与迁移、响应延迟、通信量，以及训练、增殖和推理的总成本。比较时设置算力匹配条件，并单独报告固定耗时条件；以独立初始化的群体作为重复单位。用信号移除、打乱或延迟等干预检验组织是否参与产生功能提升。

## 已加载的设计工作包

当前父任务为 tasks/T-20261002-002.md。四个工作包细化上述唯一科学目标，不是新增目标。

1. **细胞与人工基因定义及观测量**：明确状态、表达、信号、谱系和增殖的可测字段；WP1 先行。
2. **任务条件下的发育与增殖规则**：规定局部更新、表达调控、分化、分裂、状态继承和资源计算；依赖 WP1。
3. **介观结构到组织形成**：定义邻域、通信、形态和谱系指标，并区分预设几何与局部规则形成的结构；依赖 WP1、WP2。
4. **能力评估与公平比较**：选择留出任务、独立证明审查、非数学迁移测评和匹配对照；可先准备任务候选，最终冻结依赖 WP1–WP3。

## 证据与决策边界

- 结构形成与能力提升分开测量；组织形态本身不算智能证据。
- 数学结果需核验定理条件与完整推理；共识和数值实验不能代替证明。
- 结构对能力的因果作用需要对照或干预；群体内细胞和消息不是独立重复。
- 训练、扩增、通信、评估成本及失败和未完成任务都纳入记录与预算。
- 留出评估数据和答案不得泄漏到生成端；v8 继续作为独立冻结的探索性运行，不追溯称为自组织细胞实验。
