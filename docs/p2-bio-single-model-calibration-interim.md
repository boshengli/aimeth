## 解读

单个模型一次写出的程序与统计基线基本持平，生物学知识没有显著提升难基因的补全。失败多为数组形状错误等一次性编码错误。这给出 P2 的起点：组织（自测、传递、修复、淘汰）能否超过“单模型一次作答”。注意“每题取最好样本”需要答案键挑选，不是合法的解题策略，仅作上限参考。
