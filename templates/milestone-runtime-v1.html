记录

可定位每次尝试

按 run / agent / round / attempt 组织事件，以 SHA-256 串联日志，记录因果父事件。失败和负面结果保留；数学状态默认 unverified。

恢复

只接受当前租约

请求先落盘再执行。相同回执重复提交不增加结果，冲突回执拒绝。过期尝试可重试，迟到结果保留但不晋升。

衔接

请求中确有消息

拓扑边、目标轮、数量与长度由冻结配置约束。前一轮全部成功才开启下一轮；绑定记录证明消息进入请求，不证明模型理解了它。

关键语义：保证每个任务最多有一个规范的本地结果。若服务端已生成答案而 worker 在落盘前死亡，恢复后可能再次调用模型；外部推理并非“恰好一次”，未知 token 成本单独计数。

存储：SQLite DELETE 回滚日志、FULL 同步、macOS fullfsync；只用于同一主机的本地持久磁盘。依据 SQLite 事务文档、同步语义 与 Python sqlite3。进程强杀测试不等同于断电与磁盘故障测试。
