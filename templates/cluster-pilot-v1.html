组织比较怎样构成一个实验

四个固定角色组织

S：1 个 Agent 串行 16 次。
I：8 个独立 Agent，每个 2 轮。
L：8 个 Agent 分两组，仅组内传递。
X：与 L 同样每个 Agent 出度 2，一半边跨组。

统一上限 16 次调用 / 群体。终末按冻结种子抽取 1 个 Agent，不按输出好坏选取。

两道精确校准题

反导数：在 Q[x] 中求 P(0)=0，P′(x)=x³−x，提交有理数系数。

反例：反驳 ∀n≥0，n²+n+41 为素数，提交整数 n 及真因子 d。

都属于公开开发题，存在训练污染可能。尚未测 PDE 多步推导或原始 Navier–Stokes 任务。

每题 × 每服务标签 × 每组织重复 2 次。任务/重复构成配对块，块内使用相同种子、随机化组织顺序；群体之间不共享记忆。温度 0.6，top_p=1，max_tokens=512，最多尝试 1 次。实际请求保存结构化输出参数，但服务是否遵守由响应判断。

独立单位与假设边界：Agent、消息和多轮响应不是独立样本。相同输出上限不等于相同总 tokens 或 GPU 时；S 与 I 同时改变并行方式和轮数。L/X 的度数匹配是更窄的组织对照，但当前样本与任务不足以支持普遍优势。

评估器在终末选择之后运行，模型只收到题面与授权的候选消息，没有接收评估器文件、标准答案或验收反馈。精确记录了 @@EVENTS@@ 个事件和 @@MESSAGES@@ 条发送消息；原始私有日志和公开派生记录都保留。
