02 / 第一批组织

先隔离信息交换，再增加角色与动态分工

@@SVG@@

X：32 节点、4×8 分组；每轮 64 条有向边，其中 32 条跨组。图来自实际配置。

共享的实验规则

相同 solver 角色、模型接口和题面；同步轮次；只读自己的上轮 checkpoint 和被授权的消息。群体内候选始终是未验证材料。

L 与 X 保持每节点入度/出度 2、消息上限及轮数相同，只改变一半连线的位置。I 与 X 是包含通信成本的整体策略对比。

连通不等于快速传播。当前 X 是“组内环 + 组间环”；3 轮内，每个最终节点最多接触 6 个初始节点的信息。10K 下需要另测更多轮次或重连。

组织默认执行信息范围本次状态

I32 Agents × 3 轮32 条独立轨迹已实现并运行合成轨迹
L32 Agents × 3 轮8 人组内双向相邻通信已实现并运行合成轨迹
X32 Agents × 3 轮组内后继 + 下一组同位置已实现并运行合成轨迹

本轮只匹配调用槽位和输出上限，未声称总 token 或 GPU 小时相等。终末选择器固定种子、每群体选 1 个代表性 Agent，估计“典型最终输出质量”，并非 best-of-N 发现能力。正式发现效果还需要付费候选汇总选择器的独立对照。

0013 的哪些经验保留，哪些不能直接照搬？

保留探索/验证分工、少数候选、负证据、局部依赖重跑、非模型控制器，以及按未覆盖问题分配资源。数学命题必须记录假设和证明义务，不能靠共识升级证据。

旧 Step 6 的 fixed 无 LLM 调用，其他组用了不同模型和调用次数；“patterning 胜出”不能证明纯拓扑优势。旧 multiplex 的 inbox digest 主要是消息标签，新基线直接传有来源的候选片段。来源内容未重新发布。

03 / 效果测量的数学基础

先验证尺子，再用它比较 Agent

A · 控制题

精确算术，可客观验收

多项式恒等式 ×2、原函数 ×2、Bezout 整数证书、素数断言的反例。验收精确等式，不抽样代点，不执行提交代码。

已测验收器
B · PDE 桥接

从计算到证明义务

能量恒等式、L2 与 L∞ 的逻辑缺口、时空缩放。需数学专家明确题面、评分和失败条件。

已写合同，未验题
C · NS 案例

前沿级构造 / 再发现

保留 Navier–Stokes；区分 R3 的 C 与周期域的 D，外力条件和无外力问题分开。参考证明隔离。

未运行 / 未核验证明

公开开发题用于验收器校准，已知答案不能充当 held-out 测试。当前排出 6 题 × 4 组织 × 3 重复 = 72 个群体运行的计划，尚未执行这些数学模型实验；真实效果 pilot 需先取得有区分度的多步题。

实验单位是一次独立初始化的群体运行。配对块固定题目、重复索引和共同种子，不共享记忆；组内 Agent 或消息不是独立样本。重复数由实际 pilot 的成本、方差和任务家族差异再决定，当前没有正式功效承诺。

题面依据 Clay 原始陈述。公开形式化仓库提供参考，项目未构建其证明；Clay 公告不替代本项目的独立核验。完整数学合同

04 / 10K 提交设计

大量逻辑状态，受控的实际请求

N 个 Agent 状态→本地持久队列 + 预算预留（待实现）→C 个进行中请求→持久推理服务 / GPU 调度

一个活跃群体使用一个资源分配和本地日志库；独立群体可在将来的 Slurm array 中排队。TP/DP、客户端并发和缓存策略由真实模型校准，旧 skill 的 384 并发只是候选值。
