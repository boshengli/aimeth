第一次尝试为何停在 FP8 权重阶段

本地观察到日志停止在 FP8 wo_a 转换，主机 RSS 上升至 164,334,024 KiB，记录时 GPU 利用率为 0%。SGLang 上游 issue #32311 报告了其他 GPU 环境下相似的主机内存物化症状；这使它成为合理排查线索，但不足以证明两次根因完全相同。第三次通过显式 FP8 路径开关绕过了该阶段。

SGLang issue #32311 · 当前上游模型加载源码。测试镜像仍为 SGLang 0.5.16；issue 所述 GPU 与本次 H20 不同。

第二次尝试为何未返回推理结果

服务端日志显示 Triton 编译模块加载失败，随后多个张量并行调度器在读取 Triton JIT 元数据时收到空 JSON 并退出。第三次把 Triton 缓存设为作业专属节点本地路径，启动和请求通过。日志相似不等于已经确认是共享文件系统或缓存竞争导致。
